# СИНКРОН

Демонстрационный лендинг SaaS-платформы для управления командными процессами. Проект собран на HTML, CSS и Vanilla JavaScript без UI-библиотек и внешних ресурсов.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Особенности

- адаптивная вёрстка от 320 px;
- анимации появления и интерактивный hero;
- поддержка `prefers-reduced-motion`;
- доступное мобильное меню и форма;
- никаких внешних шрифтов, изображений или CDN.

## Форма

Форма заявки работает только как интерактивная демонстрация. Введённые данные не отправляются, не сохраняются и не покидают браузер. Для подключения backend замените тело функции `submitLead()` в `src/main.js` реальным API-вызовом.
